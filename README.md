# devnotes

Learning notes, mostly distilled from conversations with AI. One question per note, in plain
English. Long topics are split into linked notes.

## Adding a note

The rules live in [`AGENTS.md`](AGENTS.md): where a note goes, how it is named, how it is written.
Templates are in [`_meta/templates/`](_meta/templates/). Any AI or human can follow them.

| Where you learned it | How to save it |
|---|---|
| Claude (app or Claude Code) | Type `/devnote` at the end of the chat. The skill reads `AGENTS.md`, writes the note, and pushes. |
| Any other AI chat (ChatGPT, Gemini, …) | `dn prompt` → paste into the chat → copy the answer → `dn save` |
| A coding agent opened in this repo (Codex, Cursor, Gemini CLI, …) | "Add a devnote about …". Agents read `AGENTS.md` on their own. |
| By hand | Copy a template, write, then `dn publish` |

`dn` is an alias for [`_meta/devnote.sh`](_meta/devnote.sh). Add it once to `~/.zshrc`:

```bash
alias dn="$HOME/hanamiliv/gh/devnotes/_meta/devnote.sh"
```

| Command | What it does |
|---|---|
| `dn tree` | List folders and notes |
| `dn prompt` | Copy the distill prompt (rules + templates + current notes) to the clipboard |
| `dn save` | Save a note from the clipboard (or `dn save file.md`), then lint, index, commit, push |
| `dn publish` | Lint changed notes, rebuild the index, commit, push |
| `dn lint` | Check changed notes against the rules |
